# Jornadas nas Estrelas: Guerra Galáctica

Jogo de ação espacial para celular e computador, feito com HTML, CSS e JavaScript puro.

## Jogar

Abra `index.html` no navegador. Para testar o modo instalável/offline, publique o site em HTTPS ou use um servidor local.

## Controles

- **Celular:** joystick virtual, botão de disparo, mísseis e turbo.
- **Computador:** WASD ou setas para mover, espaço para disparar, Shift para turbo e E para lançar mísseis.
- Pause pelo botão na tela; `Esc` ou `P` também pausa.

## Publicar na Vercel

Importe este repositório na Vercel como projeto estático. Não é necessário instalar dependências nem configurar um comando de build. Use a pasta raiz como diretório de saída.

O manifesto e o service worker habilitam a instalação como PWA e o cache dos arquivos do jogo em HTTPS.
